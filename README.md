# ⏱️ StopWatch Project

A simple and interactive **Stopwatch Application** built using **HTML, CSS, and JavaScript**.  
This stopwatch lets you **start, stop, and reset** time with a clean and responsive user interface.

---

## 🚀 Features
- ✅ Start the stopwatch
- ⏸ Stop/Pause functionality
- 🔄 Reset to `00 : 00 : 00 : 00`
- ⏱️ Accurate timing up to milliseconds
- 🎨 Modern and responsive design

---

## 🛠️ Tech Stack
- **HTML5** – Structure of the stopwatch  
- **CSS3** – Styling & layout  
- **JavaScript (Vanilla JS)** – Stopwatch logic and event handling  

---

## 📂 Project Files
- `Index.html` → Main structure of the stopwatch UI  
- `style.css` → Styling and layout for stopwatch & buttons  
- `script.js` → Stopwatch functionality (start, stop, reset)
